# Stage Countdown 1.0.3

A small update to 1.0.2. Installed copies update themselves: look for the blue **Update ready** badge, then restart when you are not in
the middle of a meeting.

## What's new

- **Fixed: the ring's glow was cut off in a square.** The glow around the progress ring stopped flat at the edges of an invisible square,
  on the controller, on the stage display and in the previews. It now fades out smoothly all the way around, however strong you set it.
- **Clearer M³ badge.** It now simply reads **M³ Media Display Shown** or **M³ Media Display Hidden**, in the app and in the OBS dock.
  (A closed M³ media window counts as Hidden.)

## Download

- **`StageCountdown-Setup-1.0.3.exe`**: the installer. Use this one: it updates itself.
- Windows may show a blue **SmartScreen** warning because the app is not code-signed: click **More info → Run anyway**.
- Don't delete `latest.yml` from this release: installed copies read it to find updates.

Everything else is as described in the [1.0.2 release notes](https://github.com/carl-gian/Stage-Countdown/releases/tag/v1.0.2).
