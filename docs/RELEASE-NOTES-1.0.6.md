# Stage Countdown 1.0.6

- While OBS scene switching (and the OBS dock) is on, the app now **starts hidden in the tray** every time, so the dock and scene switching are ready without a window popping up.
- It stays an option: *Settings → OBS Scene Switching → "Start hidden in the tray while OBS switching is on"* (on by default). Turn it off to see the window at every start.
- After an update, or on the very first run, the window is still shown so *What's new* and *Help* can open.
